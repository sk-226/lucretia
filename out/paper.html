4. 読書モック (markdown_paper + ハイライター)

Krylov 部分空間法 — 読書ノート

反復法の収束は前処理行列の品質に支配される。理論上の収束次数が同じでも、固有値分布の裾が重い問題では実効的な反復回数が桁で変わることがある。したがって実装では、残差ノルムの推移を必ず記録し、停滞 (stagnation) を検出したら再スタートまたは前処理の再構成を行う。

停止基準は問題のスケールに依存してはならない。これは相対残差 norm(r) / norm(b) を使う理由でもある。詳細は Saad (2003) を参照。

丸め誤差により直交性が失われる場合、再直交化で回復できるがコストは増える。
if res < 1e-12:
    return "converged"  # 相対残差で判定
