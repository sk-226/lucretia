Notes on color

Most of a page is background and text. An accent can mark a link, a value, or a definition without coloring every word.

Keep headings clear, leave room for details, and use highlights to find a passage again.

Read a full paragraph before judging a text color.

The palette names each color. Use --lu-bg for the background.

# Keep the original order.
def unique(items):
    seen = set()
    for item in items:
        if item not in seen:
            seen.add(item)
            yield item

names = ["ink", "paper", "ink"]
count = 2
assert len(list(unique(names))) == count
